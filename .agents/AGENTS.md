# Project Rules

- **Strict Planning Requirement**: Always plan out and write/update the `implementation_plan.md` first before committing any modifications to code files, regardless of simplicity. Make sure to obtain user review and approval before execution.
- **Modern Web Guidance Requirement**: Launch the `modern-web-guidance` skill (`npx.cmd -y modern-web-guidance@latest search` + `retrieve`) first during any UI change or related HTML/CSS, layout, responsiveness, accessibility, form, dialog, popover, navigation, or client-side DOM/UX work in this system. Verify compliance with the retrieved guides and disclose applied guides on delivery.
