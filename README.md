# 🏛️ ABYAN- HRIS

**A Decision Support Information System for Competency Assessment, Training Recommendations, and Data-Driven Succession Planning in Human Resource Management**

---

## 📌 Overview

ABYAN is a web-based Human Resource Information System (HRIS) with a Decision Support System (DSS) built for the Office of the City Human Resource Management Officer (OCHRMO), Iloilo City Government. It brings Recruitment, Selection and Placement (RSP), Performance Management (PM), and Learning and Development (L&D) into one platform, using a shared competency framework aligned with CSC Qualification Standards.

---

## 🎯 Objectives

- Design a Unified Competency Framework across recruitment, performance, and training
- Identify competency gaps between employees and their positions
- Classify gaps into training streams and recommend training
- Rank succession candidates for critical positions using the Weighted Sum Model

---

## ✨ Features

| Module | Description |
|---|---|
| 👤 Applicant Portal | Browse job postings, apply online, track application status |
| 🎤 Interviewer Portal | Rate assigned applicants using structured rubrics |
| 📋 RSP | Job posting, applicant screening, scoring, and hiring |
| 📊 Performance Management | IPCR targets, Q/E/T ratings, adjectival ratings, competency map |
| 🔍 Competency Gap Analysis | Compares assessed vs. required competency per position |
| 🎓 Learning and Development | Training calendar, enrollment, attendance, training recommendations |
| 🏆 Succession Planning | WSM-based ranking of candidates for critical positions |
| 🔐 Account and Access | Role-based access, audit logs, password reset tracking |


---

## 👥 User Roles
