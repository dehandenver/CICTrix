
# ABYAN HRIS
### Human Resource Information System with Decision Support for Competency Assessment, Training Recommendations, and Data-Driven Succession Planning

**Project Website:** https://cic-trix.vercel.app/

---

## Project Overview

ABYAN is a web-based Human Resource Information System (HRIS) with an integrated Decision Support System (DSS), developed for the Office of the City Human Resource Management Officer (OCHRMO), Iloilo City Government.

The system integrates three core human resource functions: **Recruitment, Selection and Placement (RSP), Performance Management (PM), and Learning and Development (L&D)** into a unified platform.

Built around a shared competency framework aligned with Civil Service Commission (CSC) Qualification Standards, ABYAN facilitates competency assessment, identifies employee competency gaps, recommends appropriate training interventions, and supports data-driven succession planning.

## Project Objectives

- Develop a unified competency framework integrating recruitment, performance management, and employee training.
- Identify competency gaps by comparing assessed employee competencies against position requirements.
- Classify identified competency gaps into appropriate training streams and generate training recommendations.
- Evaluate and rank succession candidates for critical positions using the Weighted Sum Model (WSM).

## Key Features and Functionalities

| Module | Description |
|---|---|
| Applicant Portal | Allows applicants to browse job postings, submit applications, and monitor application status. |
| Interviewer Portal | Enables assigned interviewers to assess and rate applicants using structured evaluation rubrics. |
| Recruitment, Selection and Placement | Manages job postings, applicant screening, evaluation, scoring, and hiring processes. |
| Performance Management | Handles IPCR targets, Quality, Efficiency, and Timeliness (Q/E/T) ratings, adjectival ratings, and competency mapping. |
| Competency Gap Analysis | Identifies discrepancies between employee competency assessments and the competency requirements of their respective positions. |
| Learning and Development | Manages training calendars, seminar enrollment, attendance, and competency-based training recommendations. |
| Succession Planning | Evaluates and ranks potential candidates for critical positions through the Weighted Sum Model. |
| Account and Access Management | Implements role-based access control, audit logs, and password reset tracking. |

## Project Scope and Limitations

- Covers Recruitment, Selection and Placement (RSP), Performance Management (PM), and Learning and Development (L&D) for regular employees.
- Excludes payroll processing, Daily Time Record (DTR), and leave management.
- Developed as a web-based academic prototype.
- Designed to support human resource management processes and decision-making within the specified organizational scope.
